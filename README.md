Entry for make.fun's "Get the most reposts and likes on make.fun's newest X posts" bounty. The entry itself is a list of my public X posts, each quoting or directly replying to a different post by @makefunai, with my make.fun play code in each post's own words; `POSTS.json` holds their addresses, and `main.ts` copies it to the grader's output directory. The house reads each post's reposts, quotes and likes from X itself.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
